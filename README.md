# Tic-Tac-Toe

A tic-tac-toe game built with Ruby on Rails 8.1, Hotwire (Turbo + Stimulus), and SQLite.

## Requirements

* Ruby 3.4.10 (see `.ruby-version`)
* SQLite 3

## Setup

```sh
bin/setup
```

This installs gems, prepares the database, and starts the dev server.

## Running

```sh
bin/dev
```

Then open http://localhost:3000.

## Tests

```sh
bin/rails test
```

## Linting and security checks

```sh
bin/rubocop
bin/brakeman
bin/bundler-audit
```
